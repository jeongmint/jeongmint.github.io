# 드디어 깃허브 블로그를...

---

### 얼마나 오래 할 수 있을까 😅   

{{ website_info_text_first }}

![그래서 내 전성기는?](:late01.png){:data-align="center"}  

드디어 깃허브 블로그를 만들었습니다.

> Jekyll theme 만 2년을 고른 것 같긴 하지만...  

저는 원래 [네이버 블로그](https://blog.naver.com/tangerine_t) 를 사용했습니다. 네이버 블로그는 접근성이 편리하고 UI도 직관적입니다. 하지만 구글 검색 엔진에서 노출이 잘 안 되기 때문에 다들 블로그 이사 준비를 한다고 합니다... 깃허브로 옮겼을 때 얼마나 유입이 늘 것인가에 대해서 궁금해져서 블로그를 옮기게 되었습니다. 덕분에 잔디도 심어지고 자잘한 웹 지식도 배워갈듯 싶습니다. 

<br/>
  

입사 기념으로 금요일과 토요일을 반납하여 레포지토리를 파고, 아주 작고 소중한 웹 지식을 찾아서 어떻게 정상적으로(?) 돌아가게 만든 블로그라니 어느 정도 구색을 갖추기 시작했습니다. 

> 매우 뿌듯합니다 !

원래 깃허브 블로그를 만들기 전에는 요즘 2030 개발자들 사이에서 그렇게 핫하다는 [velog](https://velog.io) 혹은 SNS 스러운 [미디엄](https://medium.com/) 도 염두에 두었습니다. 그러나 직접 사용해보니 제가 쓰기에는 너무 심플했기에... 저는 아무래도 개발 쪽 보다는 디자이너, 아트 직군이 맞다는 것을 느꼈습니다.  

<br/>

 프로필 gif 이미지를 만드느라 하루를 다 쏟은 것 같기는 한데 귀여우니까...☘️ ![cute profile](:jeongmint.gif){:data-align="center"} 크게 봐 줬으면 합니다. 용량과 어마무시하게 영롱하게 빛나는 머리장식 ! GIF 올리면 로딩이 느려진다는 웹 마스터 친구의 잔소리가 들렸지만 귀여운 게 최고인듯 싶습니다.  

---
  
### 야심찬 포부🌱  

마크다운을 오랜만에 쓰니 재밌기는 한데 아직 익숙하지 않은 부분이 많아 계속 부딪혀 보면서 블로그를 성장시켜 나가겠습니다. 아직 폰트 적용하는 방법도 모르는 슬픈 운영자지만,, 가독성이 별로 좋은 것 같지 않아서 하루 빨리 Noto Sans를 적용해야 할텐데... 걱정이 이만저만이 아닙니다. 그래도 만들고 난 후 소감을 말씀 드리자면, 이 Jekyll theme 을 만든 개발자 분께 제일 감사하다는 말씀 전합니다.

<br/>


[MrGreen](https://jekyll-themes.com/mrgreen-jekylltheme/) 여기서 다운 받았고 이 일본인 개발자 분이 직접 친절하게 찍어주신 [유튜브 링크](https://www.youtube.com/watch?v=x9lvXBKD2Us&list=PL8XOPe9jXvWOrg6XAulRzy9MQl_-A7Yns) 를 참조하여 블로그를 만들 수 있었습니다.

<br/>

영상은 일본어이기 때문에 pc에서 한국어 자막을 적용하면 됩니다. 추후에 저도 어떻게 블로그를 꾸몄는지 관련 포스팅을 해보도록 하겠습니다. 최신 theme 이라는 것은 매우 좋지만 그만큼 열심히 찾아가며 개척해 나가야 한다는 것! 이 theme의 장점은 사용자 친화적이며 다크모드도 자연스럽다는 점입니다.
  
<br/>

블로그 게시글을 조금씩 옮기고 태그도 정리하고, 참조한 블로그들도 정리해보고 내일은 댓글과 포트폴리오 부분을 만져볼까 합니다. 사실 오늘 SEO 까지 만지긴 했는데 슈니버스 SEO 를 만질 때가 생각 나서 역시 해 본 기억이라도 있으니 익숙하기 때문에 좀 더 디테일하게 블로그를 만들고 있구나 하는 생각이 들었습니다.

<br/>

 그래도 혹시 이 글을 진지하게 읽고 계실 분들을 위해 아주 짧은 지식이라도 덧붙여 보기로 하겠습니다. 마크다운에서 어떻게 탈출문을 작성하는지 몰라 구글링을 검색한 적이 있습니다. ``\` 를 붙여도 `\` 도 함께 출력되니 제목 다는 데 의미가 없었습니다. 그러던 중 [simhyejin](https://simhyejin.github.io/2016/06/24/markdown-post-title/) 님의 블로그를 참조하여 해결할 수 있었는데 단순하게 `""` 를 양 옆에 붙여주면 되는 것이었습니다^*^  

> 마크다운 마스터가 되는 그날까지-!

<br/>

아무튼 첫 게시글은 이렇게 마무리를 하고 익숙해 지면서 기왕 만든 것 1일 1블로그 작성을 목표로 해야겠습니다. ~~과연 할 수 있을까요?~~ 디자인이나 개발 모두 욕심이 있는 만큼 양질의 컨텐츠가 많은 블로그가 되었으면 합니다😃
