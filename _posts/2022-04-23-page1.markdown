드디어 깃허브 블로그를 만들었다. Jekyll theme 만 2년을 고른 것 같긴 하지만..  

나는 원래 [네이버 블로그](https://blog.naver.com/tangerine_t) 를 사용하고 있었다. 네이버 블로그의 가장 큰 장점은 접근성이 매우 편리하다는 것이다. UI도 말할 것이 없다. 하지만 구글 검색 엔진에서 노출이 잘 안 되기 때문에 다들 블로그 이사 준비를 한다... 만약 깃허브로 옮겼을 때 얼마나 유입이 늘 것인가에 대해서 궁금해져서 블로그를 옮기게 되었다. 또 요즘 깃허브 잔디가 심고 싶어져서 바로 실행에 옮기게 되었다!  

<br/>
  

입사 기념 금요일과 토요일을 반납하여 조금씩 레포지토리를 파고, 알지도 못하는 아주 작고 소중한 웹 지식을 찾아서 어떻게 정상적으로(?) 돌아가게 만든 블로그라니 어느 정도 구색을 갖추기 시작하니 매우 뿌듯해지기 시작한다. 원래 깃허브 블로그를 만들기 전에는 요즘 2030 개발자들 사이에서 그렇게 핫하다는 [velog](https://velog.io) 로 가려 하였으나 써보니까 내가 쓰기에는 너무 심플했다. 나는 아무래도 개발 쪽 보다는 디자이너, 아트 직군이 맞다는 것을 느꼈다.

### 야심찬 포부🌱  

마크다운 문법 오랜만에 하니 재밌기는 한데 아직 익숙하지 않은 부분이 많아서 계속 부딪혀 보면서 블로그를 성장시켜 나가는 것으로 하겠다. 아직 폰트 적용하는 방법을 모르겠다. 가독성이 별로 좋은 것 같지 않아서 하루 빨리 Noto Sans를 적용해야 할텐데... 그래도 만들고 난 후, 이 Jekyll theme 을 만든 개발자 분께 제일 감사하다.  

<br/>


[MrGreen](https://jekyll-themes.com/mrgreen-jekylltheme/) 여기서 다운 받았고 이 일본인 개발자 분이 직접 친절하게 찍어주신 [유튜브 링크](https://www.youtube.com/watch?v=x9lvXBKD2Us&list=PL8XOPe9jXvWOrg6XAulRzy9MQl_-A7Yns) 를 참조하여 블로그를 만들 수 있었다.

<br/>

영상은 일본어이기 때문에 pc에서 한국어 자막을 적용하여 보면 될 것이다. 프로필 이미지 변경해주는 것부터 차근차근 가르쳐 주신다. 최신 theme 이라는 것은 매우 좋지만 그만큼 열심히 찾아가며 개척해 나가야 한다는 것! 일단 디자인이 친화적이, 다크모드도 이상한 부분 없이 예쁘게 잘 되어 있다는 점에서 이 theme 을 추천한다. 원래는 Chirpy theme 을 쓰려 했으나 로컬 서버에서는 잘 돌아가나 깃허브 링크로 랜딩이 안 되기 때문에 참 안타까웠지만 마음에 드는 theme 이 생겼으니 이제는 만족한다.    
  
<br/>

블로그 게시글을 조금씩 옮기고 태그도 정리하고, 내가 참조한 블로그들도 정리해보고 내일은 댓글과 포트폴리오 부분을 만져볼까 한다. 사실 오늘 SEO 까지 만지긴 했는데 슈니버스 SEO 를 만질 때가 생각 나서 역시 해 본 기억이라도 있으니 익숙하기 때문에 좀 더 디테일하게 블로그를 만들고 있구나 하는 생각이 들었다.  

<br/>

 내가 자꾸 잊어버려서 아주 짧은 지식이라도 덧붙여 보기로 한다. 마크다운에서 어떻게 탈출문을 작성하는지 몰라 구글링을 검색했었다. 백슬래시를 붙여도 백슬래시도 함께 출력되니 제목 다는 데 의미가 없었다. 그러던 중 [simhyejin](https://simhyejin.github.io/2016/06/24/markdown-post-title/) 님의 블로그를 참조하여 해결할 수 있었는데 단순하게 "" 를 양 옆에 붙여주면 되는 것이었다^*^  

<br/>

아무튼 첫 게시글은 이렇게 마무리를 하고 익숙해 지면서 기왕 만든 것 1일 1블로그 작성을 목표로 해야겠다. 디자인이나 개발 모두 욕심이 있는 만큼 양질의 컨텐츠가 많은 블로그가 되었으면 한다😃
