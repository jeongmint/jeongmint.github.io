# Houdini 19 설치하기

---

### Houdini 런처 다운로드

후디니는 캐나다 [SideFX](https://www.sidefx.com/download/) 사의 소프트웨어입니다. 저는 런처에서 프로그램을 돌리는 안정감을 좋아하기 때문에 로그인 한 뒤 위의 링크로 들어가 런처를 다운받습니다.

![Houdini 다운로드](:houdini01.png){:data-align="center"} 

제가 다운로드 받은 런처는 최신 버전인 `19.0.589` 입니다. Next를 눌러 계속 진행합니다. 저는 C드라이브에 다운받았습니다. 

![Houdini 다운로드](:houdini02.png){:data-align="center"} 

![Houdini 다운로드](:houdini03.png){:data-align="center"} 

### Production Build

런처를 실행시킵니다. 로그인한 후 Install 을 눌러 진행합니다. 더 안정적인 버전을 지원하는 __Production Build 19.0.589__ 를 다운 받습니다. Daily Build 는 Testing 환경의 버전이라고 합니다.

![Houdini 다운로드](:houdini04.png){:data-align="center"} 

![Houdini 다운로드](:houdini05.png){:data-align="center"} 

사용할 플러그인을 모두 활성화시킨 후 Install을 진행합니다. 저는 `3DS Max`, `Maya`, `Unreal` 에서 사용할 예정입니다.

![Houdini 다운로드](:houdini06.png){:data-align="center"} 

![Houdini 다운로드](:houdini07.png){:data-align="center"} 

열심히 다운로드 됩니다.

![Houdini 다운로드](:houdini08.png){:data-align="center"} 

> 완료 !

활성화된 Launch 버튼으로 실행시켜 봅니다. 다음과 같이 라이센스를 활성화되지 않았다는 경고문이 뜹니다.

![Houdini 다운로드](:houdini09.png){:data-align="center"} 

OK 버튼으로 닫은 후 그 뒤에 켜져 있는 창에서 가장 첫 번째 옵션인 __Apprentice License__ 를 체크하고 다음으로 진행합니다.

![Houdini 다운로드](:houdini10.png){:data-align="center"} 

다시 한 번 Launch 버튼을 누르면 후디니가 정상 실행됩니다.

![Houdini 다운로드](:houdini11.png){:data-align="center"} 

<br/>

### Apprentice License

후디니 학생용 라이선스 격인 무료 라이센스 Apprentice License 의 제한된 특징은 다음과 같습니다. 아무래도 유료 버전과 차이를 두는 것이 맞을 것 같습니다. 무료 버전이지만 기본적으로 후디니의 거의 모든 노드와 기능들을 지원합니다.

1. 1280 x 720 이상의 화질 렌더링 불가

2. 렌더링 시 우측 하단에 워터마크 삽입

3. Third party 의 렌더러(`Arnold`, `Vray` 등)을 사용할 수 없고 내부적으로 제공되는 `Mantra` 렌더러만 이용 가능

4. Alembic cache로 export 불가
