# AWS Lightsail 초간단 웹 페이지 만들기

오늘은 `AWS Lightsail` 을 활용하여 간단한 웹 페이지를 서버로 서빙해 보도록 하겠습니다.

## Lightsail 이란?

보통 AWS 를 처음 가입하게 되면 EC2 무료 계정이 나옵니다. 1년 정도 프리티어로 사용할 수 있습니다. 1년 뒤 요금제를 선택하셔야 하는데 EC2 보다 가볍게 사용하고 싶으시다면 선택지로 좀 더 AWS 콘솔에 친화적인 Lightsail 이 있습니다. 번거롭게 코드를 사용하지 않고 간단한 방법으로 서버 지식 없이 사용할 수 있다는 점에서 편리하며 소규모 웹 프로젝트에 적합하다고 할 수 있겠습니다.

자세한 사항이 궁금하시다면 AWS 공식 문서를 참조하시기를 바랍니다.

[Amazon EC2와 Amazon Lightsail의 차이](https://aws.amazon.com/ko/premiumsupport/knowledge-center/lightsail-differences-from-ec2/)
